# SIVA TIME | Siva Prasanth

A responsive personal portfolio website concept for a law student exploring the intersection of law, technology, AI and design.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For local development, you can also use VS Code Live Server.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual system, layout and animations
- `script.js` — mobile navigation, scroll progress and reveal effects
- `assets/homepage-concept.png` — generated visual homepage concept

## Before publishing

- Review all profile and experience descriptions for accuracy.
- Add a real resume PDF and update the header CTA if you want a downloadable CV.
- Add verified project URLs and individual project case studies.
- Add a professional portrait if desired.
- Add an email address or contact form if you want direct email contact.

## Deploy to GitHub Pages or Vercel

Push the extracted folder to a GitHub repository. For Vercel, import the repository and use the project root with no build command and no output directory required for this static HTML site.
